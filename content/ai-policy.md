title = "Personal AI policy"
path = "ai-policy"
+++

* Unacceptable: These are items that I personally find unacceptable in any way.
  - Using AI to write posts. I will always work through the ideas in my posts and
  describe my projects in my own words.
  - Presenting AI work as my own. I will often use AI to assist in my work (see specifics
  below) but I will never wholly represent work done by AI as my own, and when I do
  present a project where I've made use of AI, I will make sure to clearly mark how it was
  used.
* Universally acceptable: These are items I see no issue with. When using AI for these
items, I don't feel the need to add any additional attribution or recognition that I
have used AI.
  - Using AI for light editing, such as fixing typos and small grammar mistakes.
  - Using AI to assist in the technical side of scaffolding a project or in this site's
  management.
* Acceptable with attribution: These are items where I used AI to get more done than I
could have reasonably done myself, but I recognize that it was NOT all my own work and
will clearly state when AI-generated content was included.
  - Using AI to create images I use on the site. I am not a visual artist and would not
  be able to create many of the images.
  - Using AI to create interactive widgets for the posts. I extensively use LLMs as
  coding assistants, and I'll use LLM-generated widgets when I feel that they add
  something to the post.
  - Using AI as a coding assistant. I can (and have for most of my life) hand-written
  code, but I have a bad habit of starting projects and never finishing. I do see a
  trade-off between writing my own code and the pride I take in that vs finishing a
  project and the joy that brings. Everybody likely has to find their own comfort spot,
  but I have found overall I'm happier when I can work through more projects and get
  more ideas out of my head and captured in code or in words.
